# Lumpa 1.0.13：附近的人与局域网试玩

双方都使用 1.0.13 桌面预览版，连接同一个允许设备互访的 Wi-Fi 或有线局域网。应用自动启动内置连接服务并上线，不需要购买服务器，也不需要手动选择谁当房主。

1. 打开右下角「房间与好友」，上方就是「附近的人」。列表显示对方的昵称、宠物与在线状态；打开面板时搜索，并每 8 秒刷新，也可点「刷新附近」。
2. 第一次可以点「连接好友」→「我的昵称与宠物」设置自己的名字。已有昵称会保留。
3. 在附近列表点击「加好友」。应用自动连接对方的内置服务并发送申请；对方点击「接受好友」或好友申请里的「接受」。
4. 接受后点击「邀请到桌面」，对方接受邀请，宠物就会出现在桌面上。无需先进入完整个人乐园。
5. 点击朋友的宠物，面板里可私聊、邀请到桌面，或使用新的双列游戏卡片邀请五子棋、象棋、井字棋。对方接受后开局；最近玩过的游戏会显示快捷入口。

## 搜不到人时

- 双方必须打开支持「附近的人」的新版客户端。旧版只会响应房主服务信息，不会提供这版的在线用户列表。
- Windows 询问网络访问权限时，允许当前专用网络通信。应用不会替你关闭防火墙或修改网络权限。
- 校园网、访客 Wi-Fi、公共热点的设备隔离，或 VPN 路由，可能阻止广播或设备互访。可换到允许设备互访的同一路由器。
- 需要手动连接时，在「连接好友」→「高级连接」填写对方「高级网络信息」中复制的完整地址，例如 `http://192.168.0.179:4185`。IP 和端口以房主实际显示为准；只填 IP 会补默认 4185，端口被占用时必须使用实际完整地址。
- 关闭局域网发现后，仍能使用离线宠物和个人乐园；设置会保留到下次打开。

## 界面与边界

好友、设置和对战面板采用浅色半透明样式；游戏只展示目前真实可玩的三款，保留全部宠物选择和原有工位伴读。旧的好友码与手动网络入口折叠在高级信息中。

普通浏览器无法扫描局域网 UDP，因此网页预览用于查看界面或通过好友分享的网页入口参与；自动发现附近电脑需要桌面客户端。不同网络的公网联机不属于此次局域网直连范围。

局域网发现只广播公开昵称、宠物与随机设备标识，不广播会话令牌、文件地址或房间邀请密钥。随机设备标识仅用于列表去重，不用作身份认证；好友关系仍需对方接受。

测试范围包括两套独立服务之间的真实 UDP 用户发现、无需手填地址加好友、桌面邀请、三种游戏、窄屏面板，以及 Windows 原生发现与拖动回归。两台实体电脑上的防火墙及 Wi-Fi 配置仍需实际验收。
