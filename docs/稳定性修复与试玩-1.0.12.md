# Lumpa 1.0.12：稳定性修复与试玩说明

先从系统托盘退出所有旧版 Lumpa，再启动本版。不要让旧试玩版留在后台；同一标识的程序会复用已有进程。

## 这次修复

- 恢复主界面「工位伴读」原页面与原有专注、待办、衣橱和收集功能；页面内另有「打开桌面乐园」。
- 桌面宠物窗口在真正画出所选宠物后才接管显示，避免仅创建窗口就隐藏场景宠物。
- 主界面衣橱换宠物后同步更新桌面乐园；小窗不再预加载所有动物的完整动作库。
- 收回桌边时一并清除已应用的桌面背景；Esc 可以退出完整乐园。
- 收起乐园时隐藏场景与所有宠物窗口；重开复用窗口并重新确认渲染，不反复销毁重建。
- 原生鼠标按键采样维持全屏拖动；移出透明窗口、失去页面 pointerup 后也能在松手时结束，再次拖动不会锁死。
- 初始化失败显示中文错误提示并写入临时目录 Lumpa-startup-error.log；协议注册失败不再阻止离线启动。
- 提供正式 Windows x64 安装包，安装时检查 WebView2，缺少时联网下载并安装运行环境。[Tauri Windows 安装说明](https://v2.tauri.app/distribute/windows-installer/)

## 你自己先试这五步

1. 退出旧版，打开新版本；检查右下角有家具和宠物。
2. 托盘打开主界面，点击「工位伴读」；确认仍在主界面内显示原来的伴读页面，衣橱可换动物，桌边跟着换。
3. 打开完整乐园，再点击「收回桌边」，或按 Esc；重复几次。点击右上角 × 后，场景和宠物应一起收起；从主界面按钮可以重新打开。
4. 按住自己的宠物从右下角拖到屏幕上半部再松手，再拖回来；移动播放走路。双击宠物或在菜单点击「叫宠物回家」可归位。
5. 朋友优先使用完整安装包。若仍未打开窗口，保留错误提示和临时目录里的 Lumpa-startup-error.log；不能把本机启动成功当作朋友电脑已修复。

局域网加好友与邀请方式见「局域网双人试玩-1.0.11.md」，新版本仍使用同一流程。首次网络访问按需允许专用网络；无需购买服务器。网页仅在页面内运行，系统桌面宠物需客户端。

## 验证范围

单元测试与浏览器验证以 artifacts 下本版验证记录为准。原生回归覆盖主界面伴读入口、衣橱跨窗换宠物、反复展开收回、关闭重开、刷新恢复，以及真实鼠标全屏拖动。单机双客户端不等同于两台实体电脑，朋友设备的首次安装与网络权限仍需现场确认。
