# Lumpa 1.0.11：局域网双人桌面试玩

本版内置联机服务。两台 Windows 电脑在同一个 Wi-Fi 或有线局域网内即可试玩，无需租服务器、买域名、买穿透通道，也无需另外安装 Node.js。跨不同网络不属于本轮局域网直连的范围。

## 两个人怎么开始

1. 把本次 **1.0.11 免安装预览** 发给好友。双方先退出旧预览，再打开这份程序。
2. 启动后应直接在桌面右下角看到家具与宠物；此时不连接任何服务也能使用个人乐园。
3. 房主点击右上角「乐园与好友」→「连接好友」，填写昵称，点击「开启局域网房主」。第一次会准备内置运行环境，稍等数秒。
4. 如果 Windows 询问网络访问权限，允许内置服务在当前**专用网络**通信；否则另一台电脑可能搜不到或连不上。
5. 好友在相同入口点击「搜索局域网房主」，找到房主后点击「加入」。如果 Wi-Fi 禁止广播，房主可在「乐园与好友」中复制局域网地址，好友填入「局域网房主地址」再加入。
6. 双方连接同一个房主后，在「乐园与好友」看到自己的好友码。一方把好友码发给另一方，对方填入「输入好友码添加好友」，接收方点击「接受」。
7. 好友在线时点击「邀请到桌面」，对方点击「接受桌面邀请」。双方直接在桌面上相聚，不强制打开带背景的完整乐园。

## 拖动与互动

- 按住自己的宠物可在整个桌面移动，移动时播放步行动作；停止后回到待机。
- 双击自己的宠物回到小屋。也可在「乐园与好友」点击「叫宠物回家」。
- 点击好友宠物可以私聊、邀请到桌面，或邀请井字棋、五子棋、象棋。接受游戏邀请后打开对局，轮流走棋。
- 象棋点击自己的棋子，再点击标出的合法落点。包含基本走子、蹩马腿、塞象眼、炮架、过河兵、九宫、将军、自将校验，以及将死/困毙/认输结算。这是休闲好友对弈版，未实现比赛中的长将长捉等裁判细则。
- 点击门打开「进门串门」，选择自己或好友的乐园。此操作才会打开完整背景场景。
- 房主关闭应用时，局域网服务随之停止；好友会返回离线乐园。只关闭乐园浮窗、保留托盘进程时，房主服务可继续运行。

## 搜索或加入失败

先确认双方都使用本次 1.0.11、连接同一房主，房主程序仍在运行。校园网、公共 Wi-Fi、访客 Wi-Fi 的「设备隔离」可能阻止两台设备互访；这种情况可换用允许设备互访的路由器或热点。广播不可用时可尝试手动填写房主的局域网地址。

网页访客也可以打开房主地址后加上 `/friends.html` 加入，但浏览器中的宠物只能在页面内拖动；系统桌面浮窗需要 Windows 客户端。

## 开发与打包

Windows x64 使用与 `vendor/node-runtime-version.json` 匹配的 Node 版本，运行 `npm ci`、`npm run desktop:prepare` 后再执行 Tauri 构建。`desktop:prepare` 会生成网页和内置联机运行包；不把 node_modules、服务记录、用户文件、密钥或运行包提交进源码仓库。

测试命令：`npm test`、`node scripts/smoke-social.mjs --offline-only`、`node scripts/smoke-social.mjs`。Windows 原生实测使用 `node scripts/smoke-native-park.mjs`，会临时启动独立预览、移动测试宠物并恢复鼠标位置，结束后关闭测试进程。
