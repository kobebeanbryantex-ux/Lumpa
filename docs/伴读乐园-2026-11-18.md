# 伴读乐园：本次行为与试玩说明

## 已接入

- 主窗口「伴读乐园」统一打开原好友小屋与工位伴读入口。
- 启动时先进入个人离线乐园，不等待联机服务，也不要求填写服务地址。
- 离线可切换全部宠物、创建本机小屋、布置家具、保存背景、使用专注计时和每日待办。
- 家具布局保存在 localStorage；自选 PNG、JPEG、WebP、GIF、MP4、WebM 背景保存在本机 IndexedDB。视频静音循环。
- 桌面默认是右下角小场景（560 × 167 逻辑像素，按显示器 DPI 换算，屏幕较小时缩小），只显示家具、地板与宠物。操作菜单按需展开。
- 拖动宠物沿地面移动时播放步行动作；向上拖或拖出场景左右边缘时交给独立透明宠物窗口，可继续拖至屏幕其他位置。
- 独立宠物双击回家，也可在「乐园与好友」点击「叫宠物回家」。关闭乐园会一并关闭独立宠物窗口。
- 主窗口与乐园使用同一份计时、待办、礼物、成长和中断残留物存档。按真实截止时间恢复计时，使用 Web Locks 避免多窗口重复结算。
- 连接失败后回到本机乐园，不把个人场景锁在连接表单中。

## 试玩

1. 网页预览：运行 `npm run web:verify` 与 `npm run social:start` 后打开 http://127.0.0.1:4180/friends.html 。页面会自动进入个人乐园。
2. 桌面预览：打开本次免安装预览，在顶部选择「伴读乐园」。右下角出现家具和宠物。
3. 点「工位伴读」使用计时与待办；点「乐园与好友」换宠物、布置、开合完整乐园或连接好友。
4. 按住宠物向上拖出小屋，继续在桌面拖动；双击独立宠物返回小屋。

## 持续保留的产品要求

- 默认奶油法斗，所有宠物可选。新增宠物不能只加目录卡片而没有可用动作。
- 拖动是步行，动作依移动距离推进，停止时回到待机；脚底使用透明像素实际边界定位，避免跑步和鞠躬悬空。
- 本机桌面与带背景的个人乐园是同一份布置。背景可以自主选择是否应用到桌面。
- 好友来访、换房、游戏邀请接受后开局、私聊、文件与宠物分享继续保留。
- 网页访客可以在页面内互动；跨电脑互联仍需双方可访问的同一联机服务。离线乐园与跨电脑联机是两种运行条件。
- 先提供网页和免安装预览，验收后再做安装包，避免反复安装。

## 验证边界

`npm test` 检查原有引擎；`scripts/smoke-social.mjs --offline-only` 检查离线存档、可见宠物、共享计时与一次结算、二维拖动和桌面窗口交接请求；完整 `scripts/smoke-social.mjs` 检查双浏览器访客联机、背景、权限、文件、私聊、宠物分享和两种游戏。浏览器里的桌面模拟不能替代 Windows 原生拖动的实际验收。

离线背景目前只保存在当前应用或浏览器数据内，未自动上传到好友服务；浏览器不能在网页之外创建系统桌面宠物窗口。
