# Lumpa 好友小屋

## 1.0.13 自动发现

桌面客户端默认启动内置服务并上线；在「附近的人」查看同一网络的昵称与宠物，点击即可自动连接并发好友申请。无需普通用户手填地址。三款小游戏已使用卡片入口。详见 [新版试玩说明](../../docs/附近的人与局域网试玩-1.0.13.md)。下列本机服务命令用于开发调试。

## 本机预览

```powershell
npm run web:build
npm run social:start
```

打开 [好友小屋](http://127.0.0.1:4180/friends.html)，填昵称并选择第一只宠物。点「房间与好友」创建房间，复制邀请链接到另一个浏览器或无痕窗口。每个浏览器身份独立，同一浏览器的两个普通标签页共用身份。

拉着角色左右移动即可看步态。点同房的角色可以申请好友或挑战五子棋、井字棋。好友接受申请后，双方可以用私聊传文字、文件和内置宠物副本。选中分享的宠物后可带去其他联机房间。

## 一个人试玩双人对战

1. 打开 Windows 免安装预览，点主窗口的「好友小屋」。服务地址使用 `http://127.0.0.1:4180`。输入昵称后，在「房间与好友」里建房，也可以用已有房间。
2. 点「房间与好友 → 邀请好友」，展开「本机浏览器试玩链接」，点击复制。在 Chrome 或 Edge 按 **Ctrl+Shift+N**，把链接粘贴到无痕窗口。给访客取一个不同的昵称，选另一只宠物。
3. 回到桌面端，单击访客的宠物，找到「发起对战」。先在「井字棋」那一行点「邀请」，再在网页端点「接受邀请」。同房成员可以直接对战。
4. 发起人先落黑棋。想快速测出胜负，桌面端依次下第一行的左、中、右三格，网页端在中间轮次下第二行的左、中两格。两端都应同步落子和胜负。
5. 关掉棋盘面板后，可以从「房间与好友」里的「继续对局」回到原棋盘。试完井字棋后，再发起「五子棋」挑战。五子棋用 15×15 棋盘，横、竖或斜向连成五子获胜。

链接里的 `127.0.0.1` 适合同一台电脑测试。异地好友需要能访问的 HTTPS 联机地址。如果本机服务已退出，在本项目目录运行 `npm run social:start`。

## 桌边与乐园

- **桌边**默认是透明的家具、地板和宠物长廊。浏览器里的「桌面预览」可查看相同布局。每个乐园都可以在「房间与好友」里开启或关闭「应用背景到桌面」。这个开关保存在本设备。
- **乐园**是房主自己的完整空间。进入好友乐园时默认显示背景和家具，已经加为好友的人可从乐园列表直接串门。其他访客可用邀请链接进入。
- **布置乐园**允许房主选择地板和家具，在长廊上拖动位置，调整尺寸与配色，再保存并同步给同房好友。背景支持 PNG、JPEG、GIF、WebP、MP4 和 WebM，单个文件最多 25 MB。视频默认静音循环。
- **换宠物**列出当前版本的全部内置宠物，即使本次没有收到宠物礼物也可以更换。收到的宠物会显示在收藏状态中。

在 Windows 客户端点主窗口的「好友小屋」，或者悬浮宠物工具栏里的「友」。开发版默认通过 Vite 的 4173 端口转发到 4180。未配置公共服务的版本默认连接本机 4180。开发和自托管地址可以在「联机设置」里改。

## 给异地好友使用

在一台可公开访问的主机运行服务，并通过 HTTPS 反向代理暴露同一域名的网页和 `/social`。代理转发原始 Host 和 WebSocket Upgrade，把请求体上限设置为至少 25 MB。反代上游使用默认 `127.0.0.1:4180`。服务在项目根目录启动，静态页面和桌宠素材从构建后的 `dist` 读取。

| 环境变量 | 用途 |
| --- | --- |
| `LUMPA_SOCIAL_PORT` | Node 服务端口，默认 4180 |
| `LUMPA_SOCIAL_HOST` | Node 监听地址，默认 127.0.0.1 |
| `LUMPA_SOCIAL_DATA` | 服务数据目录，默认项目根下的 `.social-data`。部署时使用持久目录 |
| `LUMPA_SOCIAL_ORIGINS` | 额外允许的页面来源，以逗号分隔。网页和服务共用域名时无需填写 |

公共服务可以使用托管平台提供的 HTTPS 地址。构建桌面端前将地址设为 `VITE_LUMPA_SOCIAL_URL`，用户打开「好友小屋」便会直接连接。两位桌面用户都连到该服务后，房主只需发「房间与好友 → 邀请好友」里的房间码，对方从同一个菜单输入即可。未装 Lumpa 的好友可以打开「复制网页邀请」得到的链接。

`127.0.0.1` 指向访问者自己的电脑。本机地址生成的试玩链接和房间码仅在连到该本机服务时有效。

临时公网试玩使用独立服务。设置 `LUMPA_SOCIAL_PUBLIC_TEST=1` 并把 `LUMPA_SOCIAL_DATA` 指向一个新的空目录。此模式只提供好友小屋页面和所需素材。连接地址仍需通过托管平台或经过授权的临时入口提供。

当前服务使用独立的设备会话，房间、好友、最近私聊和礼物保存在单实例的磁盘目录。内置模型礼物是可装备副本，自定义模型可作为文件手动发送。单文件上限 10 MB，暂存 7 天。服务器负责分发与存储私聊内容，部署时应由房主信任的服务运营方管理。

先构建网页，再运行 `node scripts/smoke-social.mjs`。它会用无界面的 Chromium 检查邀请、拖动、私聊、文件授权、宠物赠送和游戏。加上 `--games-only` 可以单独验证井字棋和五子棋。默认使用 Windows Chrome，也可以用 `CHROME_PATH` 指定。
