# 🐾 Lumpa 1.0 - Windows 桌面 AI 奇妙伴侣

Lumpa 是一款专注于**全透明独立停靠、智能拟人情感陪伴与极客级隐私安全**的 Windows 桌面伴侣应用。1.0 版本将全透明桌宠渲染、按需交互菜单、自定义创宠、本地数据保护与安全发布链路统一为一套可公开审计的现代化架构。

---

## 🌟 核心特色与新增亮点

- 🐱 **全透明独立桌宠 (Win32 DWM 硬件级透明)**：告别白框与遮挡面板，独立停靠在桌面图标与软件窗口上方，实现真正的纯净独立展示。
- 🖱️ **按需浮现与零干扰悬浮**：平时保持静默独立动物形象；**仅在鼠标移入或点击触碰时**平滑淡出交互菜单（`锁` `说` `动` `食` `□` `×`），完全不占用桌面空间或干扰日常工作。
- ⚙️ **主界面智能折叠工具栏**：主窗口工具栏默认收起为右下角微型 `⚙️ 工具` 胶囊，点击平滑展开，点击空白处自动恢复折叠。
- 💬 **智能拟人语音与口型匹配**：结合大模型对话，支持多音色合成与动态嘴型动画匹配。
- 🎨 **一键 AI 自定义创宠**：支持上传任意宠物或动漫照片，自动完成智能抠图与表情嘴型动画切图生成。
- 🔒 **严格本地隐私与 Stronghold 加密**：API Key 及刷新令牌采用 Stronghold 加密并由 Windows 凭据管理器保护；所有聊天记录与性格记忆 100% 本地 SQLite 存储，绝不自动上传云端。

---

## 🛡️ 架构与安全特性

- **严格 CSP 与沙盒隔离**：Tauri v2 架构，禁用全局 Tauri API；浏览器层不直接请求模型或下载文件，所有网络请求均由 Rust 受限安全层代理校验。
- **便携数据加密备份**：数据备份（`.lumpa-backup`）采用 **Argon2id + AES-256-GCM** 高强度加密，且备份包中**严格剥离任何 Key 或访问令牌**。
- **隐私中心与诊断控制**：分类查看、导出与彻底删除本地数据；诊断日志预览后手动导出，使用统计默认关闭。
- **真·彻底卸载保护**：NSIS 卸载器提供选择性数据擦除；若 Stronghold 凭据或本地应用数据清除失败会自动终止卸载，杜绝“假删除”。

## 🚀 本地开发与编译指南

### 环境要求
- Windows 10 / 11 (64-bit)
- Node.js 22+
- Rust stable
- WebView2 Runtime

### 开发与测试命令

```powershell
# 1. 安装依赖
npm ci

# 2. 编译前端网页资源
npm run web:build

# 3. 运行前端与 Rust 单元测试
npm test
cargo test --manifest-path src-tauri/Cargo.toml --all-targets

# 4. 启动桌面开发模式
npm run tauri:dev
