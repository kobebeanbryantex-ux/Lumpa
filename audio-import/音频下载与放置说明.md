# Lumpa 桌宠音效包：下载与放置说明

## 你下载后放到哪里

把文件放进下面这个文件夹，**不需要重新安装**：

`%LOCALAPPDATA%\\Lumpa\\audio`

在 Windows 文件资源管理器的地址栏粘贴上面的路径并回车即可打开。文件扩展名可用 `.wav`、`.mp3`、`.ogg` 或 `.m4a`；建议优先下载/导出为 **WAV、44.1 或 48 kHz、16-bit、单声道**。

文件名必须与下方清单一致。例如把一段温柔的猫叫保存为 `meow_gentle_01.wav`。下载时请把原网页链接、作者和许可证填写到 `音频授权登记.csv`，以后商业化上架时可直接核验。

## 可用音效网站

1. [Pixabay：猫叫搜索](https://pixabay.com/sound-effects/search/cat%20meow/) / [呼噜搜索](https://pixabay.com/sound-effects/search/cat%20purr/) / [狐狸搜索](https://pixabay.com/sound-effects/search/fox/) / [狼搜索](https://pixabay.com/sound-effects/search/wolf%20howl/)
   - 选择每个音效详情页提供的下载项，并保存原始网页链接。Pixabay 的内容许可允许在符合限制的前提下免费使用、修改，并用于商业作品；不能把音频作为独立素材包转售。详见 [Pixabay Content License](https://pixabay.com/service/license-summary/)。
2. [Freesound](https://freesound.org/)
   - 搜索时务必只选 **CC0**；不要选 **CC BY-NC**。CC0 最适合商业版；若使用 CC BY，则必须保留作者、作品名、链接和许可证，并在产品鸣谢页署名。详见 [Freesound 的许可说明](https://freesound.org/help/faq/)。

不要从短视频、影视、游戏录屏或 YouTube 直接截取声音；它们通常不能被合法植入商业软件。

## 放好后的规则

- 关掉并重新打开 Lumpa；它会优先读取这一文件夹中的新声音。
- 同一种动作有多个编号时，桌宠会轮换播放，避免每次都像同一张贴图一样重复。
- 白猫、橘猫、暹罗、布偶等猫模型共用猫声音池；狐狸和狼崽优先使用自己的声音池。某个狐狸/狼崽文件尚未放入时，会温和回退到猫声音，不会报错。
- 后续想替换任意声音，只需用同一个基础名覆盖旧文件，例如用新的 `meow_gentle_02.mp3` 替换旧文件。
